RoomInfoCard & GroupIcon — unmodified game code, running in a browser tab

Java → javac → TeaVM → JavaScript, with Graphics2D backed by Canvas2D. The hit-testing below is the desktop build's own handleMouseMove and handleClick, reached through real DOM events.

  • Hover the gear (top-right of the card) — it brightens
  • Click the gear — handleClick returns true
  • Scroll over the canvas — resizes the icon
  • Click the canvas, then press Space — toggles the card
